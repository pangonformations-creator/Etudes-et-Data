# TD2 : Seconde Roue

Études et Data, partie 2 : principaux outils et leurs fonctions.

Site statique pédagogique. Tous les tableaux, textes, noms de profils et domaines concurrents sont fictifs. Les interfaces sont adaptées pour explorer des fonctions, sans affiliation aux éditeurs. Aucun compte de plateforme, aucune clé ni base de données nécessaire.

## Utilisation

Ouvrir le TD2 depuis la navigation du site ou depuis `td2/index.html` sur un hébergement statique. Les étudiants répondent sur un document ou une présentation séparée. Les champs de recherche filtrent uniquement les rapports ; aucune réponse ni donnée personnelle n’est enregistrée.

## Déploiement GitHub Pages

Le ZIP fourni contient les fichiers du site directement à sa racine. Les déposer dans un dépôt GitHub, puis choisir la branche et la racine dans Settings > Pages, ou déployer ces fichiers avec le workflow de son établissement. Conserver `.nojekyll`, les sous-dossiers et les chemins relatifs.

## Parcours conseillé

Commencer par « Le sujet du TD ». Prévoir environ trois à quatre heures en binôme pour les six étapes : visibilité, parcours, contenus sociaux, écoute et sentiment, CRM et automatisation, synthèse. Rendu : cinq slides ou une note de deux pages, avec une annexe de preuves. La décision porte sur trois priorités et un budget maximum de 600 €, en visant 70 essais confirmés en mai. Chaque dossier indique les pièces, le travail et les traces attendues.

Le graphique Trends affiche les mois et indices au survol, au toucher et au clavier. Les légendes permettent de masquer une série sans recalculer la normalisation. Les courbes restent une simulation dans un périmètre fixe.

## Pièces

Documents D01 à D10 dans le site. Rapports complets dans `downloads/`, CSV UTF-8 séparés par point-virgule et fichier JSON global. Voir le dictionnaire D10 et les notes de chaque outil avant de rapprocher les chiffres.

## Accès

L’aperçu Sites garde l’audience privée du site existant. Pour la distribution aux étudiants, publier les fichiers sur l’hébergement choisi, notamment GitHub Pages, selon les règles de l’établissement.
